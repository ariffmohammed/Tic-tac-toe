Tic Tac Toe 🎮
A two-player Tic Tac Toe game that runs in the terminal, built with Python.
How to Play
	1.	Run the file using Python 3
	2.	Enter names for Player 1 and Player 2
	3.	Players take turns entering a position number (1-9) based on the board below
	4.	First player to get 3 in a row wins!

1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9


Features

	∙	Two player mode
	∙	Win detection for all rows, columns and diagonals
	∙	Draw detection
	∙	Play again option
